# Security-Headers-Checker
Python tool for analyzing HTTP security headers (Bug Bounty / Pentest / Educational use)
## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/wininourson-oss/Security-Headers-Checker.git
cd Security-Headers-Checker


Install dependencies:
pip install -r requirements.txt


Run the tool:
python3 security_headers_checker.py https://example.com
